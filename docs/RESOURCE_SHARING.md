# AimiliVPN 资源共享

## 目标

通过现有 8443 HTTPS 管理入口，让两台或多台 AimiliVPN 服务器安全交换 VPN Gate 节点资源。共享的是资源数据库信息，不共享管理员账号、后台密码、SOCKS5 密码、OpenVPN 配置正文或本机文件路径。

## 建立关系

1. 服务器 A 在「管理员 → 资源共享」填写对方服务器名称和允许 IP/CIDR，并生成长期邀请码；邀请码可以创建多个。
2. 服务器 B 只需要输入 A 的服务器 IP/域名 + A 的邀请码；不需要再填写允许 IP。
3. A 校验邀请码、来源 IP 后建立入站共享关系，并生成专用资源访问令牌；邀请码不会因为加入一次而失效。
4. B 同时向 A 提交自己的邀请码后，A 的关系表会把同一服务器识别为“双向共享”；只有单边关系时显示“单向共享”。
5. 自动同步周期独立保存为每小时、每天或每周；“立即同步”不受周期限制。
6. 已建立关系可以修改远端 IP/域名、对方邀请码、名称和同步周期，也可以直接删除。

## 网络与安全

- 资源接口固定使用现有 HTTPS 8443，不新增公网端口。
- 资源 API 不复用管理员 Cookie。
- 资源访问使用独立随机访问令牌，并要求来源 IP/CIDR 在 Peer 白名单中。
- 邀请码不设置过期时间，可以创建多个；系统同时保存邀请码明文用于管理员查看/复制，并保存哈希用于校验。邀请码可随时撤销。
- Peer 配置文件 vpngate_data/resource_sharing.json 权限为 0600。
- 对端发送的健康状态只能作为远端观察数据，不能直接把资源提升为本机 HOT/AVAILABLE。
- 共享节点进入 Master Pool 后，由本机探测决定是否成为本机可用节点。
- 前端不再要求填写“最多同步节点”；同步使用系统内置安全上限 5000 条/Peer，不作为用户配置项。
- 邀请码本身绑定“对方服务器名称 + 允许 IP/CIDR”。例如 1.2.3.4/32 只允许该 IPv4；0.0.0.0/0 允许所有 IPv4；IPv6 全部放开可使用 ::/0。
- “双向共享”由同一远端实例的入站+出站关系自动合并显示；“单向共享”表示只有一侧关系存在或其中一侧已停用。
- 主页面右侧固定入口已调整为“官网入口”，仅用于集中访问 ILovestudy 官网、IP 节点检测、博客、YouTube 和 Telegram 等官方入口，不再展示 VPS 购买推荐。
- 创建邀请码的一侧通过允许 IP/CIDR 控制谁可以访问本机；加入对方的一侧只填写对方服务器 IP/域名 + 对方邀请码。
- 同一邀请码可以被同一授权 IP 多次使用建立/更新关系，不会因为一次 JOIN 被消耗。
- Peer 可以暂停、继续、修改名称/白名单/同步周期，也可以删除；删除时只清理该 Peer 独占且尚未被本机验证的共享资源。
- 邀请状态分为“有效 / 已撤销”；撤销立即停止授权但保留记录，只有再次点击“删除”才永久移除邀请码及对应入站 Peer。
- “修改”使用独立编辑界面，不再使用浏览器 prompt；可按关系类型修改服务器名称、允许 IP/CIDR、对方 IP/域名、对方邀请码和同步周期。
- 同步周期默认 6 小时，可配置为小时、天、周；后台每 5 分钟仅执行一次轻量到期扫描。

## 同步去环

同步请求会告诉远端本机实例 ID。远端在导出资源时跳过刚从该 Peer 学到的共享资源，避免 A → B → A 的资源回环。

## 数据范围

每条共享资源只包含 Host/IP、国家、协议、传输方式、端口、运营主体/ASN/位置/IP 类型等公开节点信息，以及健康摘要。不会包含 OpenVPN 配置正文、配置文件路径、认证凭据。

## 协议显示

UI 统一显示：
- OpenVPN
- SSL-VPN（SoftEther VPN）
- L2TP/IPsec
- SSTP

协议标签可打开对应的 VPN Gate 官方说明页面。

## 节点连接与自动兜底

- UI 相同“协议 + IP + 端口”的重复资源只显示一条；底层 Master Pool 仍保留候选端点，用于连接失败时尝试备用端点。
- 默认节点显示顺序按“当前连接 → 可用性 → 已测延迟（低到高）→ 协议/评分”排序；不同协议的低延迟可用节点不会因协议分组被排到高延迟节点后面。
- 手动连接某个节点失败后，系统会自动进入统一 Hot Pool，最多继续尝试 6 个可用候选；国家/IP 类型偏好仍按现有路由策略决定。固定 IP、仅收藏等硬约束模式不自动突破用户明确设置的范围。
- 后台正在拉取、国家优先检测或周期检测时，用户仍可手动切换节点；后台检测资源与手动连接使用独立的手动连接锁，检测任务不会继续抢占正在建立的用户连接。
- SoftEther/SSL-VPN、SSTP、L2TP/IPsec 在正式接管 8500 前执行真实协议/出口验证；验证失败会返回实际原因而不是笼统的“单一 Mirror”拦截。
- IP 类型筛选明确区分住宅 IP、机房 IP、移动网。
- 状态、国家、协议、IP 类型四个筛选器统一使用可点击的自定义下拉控件，避免浏览器原生下拉在深色主题下出现点击/样式不一致。
- 自定义筛选选项使用事件委托并避免在后台轮询期间无条件重建打开菜单的 DOM，减少点击失效和“点了没反应”的竞态。
- 前端后台轮询增加超时与单次请求互斥，避免慢请求重叠造成页面卡顿。
- 页面、弹窗和下拉列表统一使用深色细滚动条，避免浏览器默认白/灰色滚动条破坏 UI。

## VPN Gate 数据源

主站和官方镜像站独立抓取；镜像列表来自 VPN Gate 官方镜像页面。单个镜像失败不会阻塞其它来源，来源在合并后的资源中保留用于多源确认。

## 日志

日志接口只读取当前日志文件的尾部窗口，默认最多返回 1200 条或最近 1 MiB，降低大日志导致的页面卡顿。管理员可以清空今日日志或执行旧日志清理；旧日志清理规则为删除 3 天前文件。

## 环境变量

RESOURCE_SHARE_SYNC_INTERVAL_SECONDS 只控制后台到期扫描频率，默认 300 秒；每个 Peer 的实际同步周期独立保存为小时/天/周。
